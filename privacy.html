Privacy policy

Last updated: 10 November 2026

Power is a personal assistant used by one person, Ruben, on his own Google account. It has no other users.

What Google data it uses

  • Gmail: reads messages and labels, applies labels, and creates drafts or sends mail only when Ruben approves it.
  • Google Calendar: reads events and creates or updates events in Ruben's calendar.
  • Drive, Docs and Sheets: opens files only when Ruben asks for it.

Where it is kept

Data is processed and stored only on Ruben's private server and used only to help him. It is never sold, never shared with third parties for advertising, and never used to train general AI models. Text may be sent to the AI model provider that runs the assistant, solely to produce Ruben's own summaries and replies.

Power's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Stored copies on the server are deleted on request.

Questions: open an issue on this GitHub repository.
